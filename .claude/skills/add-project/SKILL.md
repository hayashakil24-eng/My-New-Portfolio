Add a new project to the portfolio:

1. Add a project card to the Projects section in `index.html`, matching
   the existing card markup and style exactly (same classes, same structure).
2. Create a detail page at `projects/<slug>.html`, using the same theme,
   header, nav, and footer as the other project pages.
3. Detail page content, in this order: the real problem, the actual
   decisions made, one concrete result or metric, a live link or screenshot.
4. Never mention AI tools anywhere in the copy (see CLAUDE.md).
5. Keep the copy short. No filler, no generic phrases.
